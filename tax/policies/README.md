# Tax Pod Policies

This directory contains enforceable policies for data handling, security, and operational constraints.

## Policy Documents

- `data_minimization.md` - What data is collected vs refused
- `redaction_rules.md` - PII patterns and redaction requirements
- `retention_and_audit.md` - Evidence record retention and immutability
- `disclaimers_and_limits.md` - User-facing constraints and boundaries
- `safe_answering_rules.md` - Requirements for all system responses

All policies are fail-closed: when in doubt, refuse or redact.
