# Tax Pod Prompts

This directory contains system prompts and templates for Tax Pod agent operations.

## Directory Structure

- `system/` - System prompts for different agent roles
- `templates/` - Response and evidence templates

## System Prompts

- `tax_triage_system.md` - General tax case triage
- `irs_notice_triage_system.md` - IRS notice-specific triage
- `payment_plan_first_system.md` - Installment agreement guidance
- `cost_seg_support_system.md` - Cost segregation study support

## Templates

- `response_template.md` - Standard response structure
- `evidence_template.md` - Evidence record format
- `vetting_checklist.md` - User/professional verification checklist

All prompts enforce safe_answering_rules.md requirements.
